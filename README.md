# FanGame

> 팬 캐릭터들이 등장하는 **로그라이트 전투 게임**
> Unity 2D / C# / DOTween

---

## 📖 게임 소개

5명의 플레이어블 캐릭터 중 하나를 선택해 맵을 탐험하며 전투, 이벤트, 휴식 노드를 거쳐 최종 보스를 처치하는 로그라이트 게임입니다.  
전투에서 승리하면 3가지 보상 중 하나를 선택해 캐릭터를 강화하고, 모든 스테이지를 클리어하면 선택한 캐릭터의 전용 엔딩이 재생됩니다.

---

## 🎮 조작법

| 키 | 행동 |
|---|---|
| `Space` | 회피 |
| `Q` | 패링 |
| `E` | 스킬 사용 |
| `Tab` | 플레이어 정보 ↔ 인벤토리 전환 |
| `ESC` | 일시정지 / 설정 |
| 마우스 좌클릭 | 적 타겟 변경 |

---

## 🧑‍🤝‍🧑 플레이어블 캐릭터

| 캐릭터 | 스킬 |
|---|---|
| **바바** | 랜덤 마법 (불·얼음·대지) 전체 공격 |
| **네모** | 다음 공격 크리티컬 100% + 크리데미지 +50% |
| **로즈마리 집사** | 최대체력 50% 비례 단일 공격 + 흡혈 |
| **해포리** | 공격속도 × 2회 연타 (타당 25% 피해) |
| **신자** | 패링 시 공격력의 50% 데미지로 반격 |

---

## 🗺️ 게임 흐름

```
메인 메뉴 → 캐릭터 선택
    ↓
맵 선택 (절차적 생성, 11층)
    ↓
노드 종류에 따라 분기
 ├─ ⚔️  일반 전투  → 보상 선택 (3종 중 1)
 ├─ 💀  엘리트 전투 → 보상 선택
 ├─ 📜  이벤트      → 선택지에 따른 결과 적용
 ├─ 🏕️  휴식        → 수면(HP 50% 회복) / 명상(FP 최대+1) / 훈련(랜덤 스탯 강화)
 └─ 👑  보스 전투
         ├─ 패배 → 게임 오버
         └─ 마지막 스테이지 보스 클리어 → 캐릭터 전용 엔딩
```

---

## ⚔️ 전투 시스템

- 플레이어와 적이 **공격속도 기반 액션 게이지**를 채워 자동 공격
- 플레이어는 **회피 / 패링 / 스킬**을 직접 입력해 전투에 개입
- 패링 성공 시 상대에게 **무장해제** 적용
- 마우스 클릭으로 **타겟 수동 변경** 가능
